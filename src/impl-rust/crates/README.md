# Crate stubs land here

```
crates/
├── dashd/                    cargo new --bin crates/dashd
├── dashctl/                  cargo new --bin crates/dashctl
├── dash-sim/                 cargo new --bin crates/dash-sim
├── dash-sim-client/          cargo new --bin crates/dash-sim-client
└── dashsim-client-sdk/       cargo new --lib crates/dashsim-client-sdk
```

After creating a crate, uncomment its line in the workspace `Cargo.toml`.

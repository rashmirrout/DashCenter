# `gen/go/` — generated gRPC/protobuf stubs

Do not hand-edit. Regenerate with one of:

```powershell
make protos                        # from src/impl-go/  (buf, default)
$env:PROTOGEN="protoc"; make protos  # plain protoc
```

These files are **checked in** so contributors can `go build ./...`
without installing buf or protoc first.
